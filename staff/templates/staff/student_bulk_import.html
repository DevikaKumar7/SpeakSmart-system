CSV Format Guide

Your CSV must have a header row as the first line. Column names are case-insensitive.

● Required ● Optional
Column Name Type Example
student_id RequiredSTU001
first_name RequiredJohn
last_name RequiredSmith
email Requiredjohn@example.com
phone Optional9876543210
gender OptionalM / F / O
date_of_birthOptional2000-06-15
batch OptionalBatch A
password OptionalPass@123

Example CSV:

student_id,first_name,last_name,email,phone,gender,batch
STU001,John,Smith,john@mail.com,9876543210,M,Batch A
STU002,Jane,Doe,jane@mail.com,9123456789,F,Batch B
STU003,Alex,Kumar,alex@mail.com,,,Batch A
💡 Tips:
  • The first row must be the header row
  • Duplicate student_id or email rows are skipped
  • If batch column is missing, the Default Batch above is used
  • Login username = email prefix (before @)
  • If no password column, passwords are auto-generated
